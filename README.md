# Flight Reservation App

This project is an application that enables flight reservations. It retrieves data from Amsterdam Schiphol Airport and displays real incoming and outgoing flights.

## Features

- Flight search 
- Booking reservations  
- Ticket viewing 

## Installation  

To run the project locally:  

1. Start the backend services by navigating to the `/backend` directory and running the command `npm start`.  
2. Start the project (Frontend) by running the command `npm start` in the root directory.
